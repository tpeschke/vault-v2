# Page type 1 first-page view
status: accepted   date: 2026-10-01

Decision: The v2 page-type-1 view matches the first page of the official blank sheet: two columns, same section order and labels. The form uses the vault set (HamletOrNot, oldClaude, Source Sans 3). Character-object values on v2 sheets use Kalam Regular 400 via class `character-value`. The strength label stays **Cultural Strength**, not the sheet’s “Culture Strength.”

Why: The attached blank sheet is the layout source. Vault typefaces and the existing Cultural Strength name are the two listed exceptions.

Constraints it imposes:
- Left: Name, Ancestry, Class / Subclass / Lvl, CrP, Stats, Characteristics / Emotional Capacity, Current Emotions, Social Suites, Reputation, Cultural Strength / Social Skill Discount, Descriptions, Flaws, Favor.
- Right: Bonfire wordmark (attached logo: flame + BONFIRE + “The Roleplaying Game”) at the top, then Positions (static legend), Self Doubt, Damage, Stress, Defenses, Attacks. Compress the blocks below the logo so the page still fits `.page` height (1036px), except the Vitals die row: that row’s height follows the die PNGs. Do not shrink those glyphs to protect page height. Do not further compress to make room for attack/defense notes; if those overflow, record it. Do not use the v1 flame-only `logo-black.png` plus HTML title.
- Do not put Goals, Temperaments, Relationships, or Movement on this page.
- Form fonts stay HamletOrNot (section `h1`/`h2`), oldClaude (`em`/`strong`), Source Sans 3 (default `p`). Character-object values on every v2 sheet page use Kalam Regular 400 (`className="character-value"` on each interpolated node). Load Kalam via the existing Google `@import` in `index.css` (`family=Kalam:wght@400`). CSS `.v2 .character-value` lives in `View.css`. Do not mark Positions, die image cells, Anointed, static `/` (`p.slash` and slash spans), or v1/home. Display `p.character-value` stay 15px and `min-height: 17.38px`. Do not change those display metrics to make Edit match. Edit controls copy the display box (`edit-character.md`). Label “Cultural Strength” unchanged. (Revised: fonts were the vault set for both form and fill-in.)
- Social suite labels and payload keys are Influence / Inform / Inspire / Intimidate. Draw order: Influence, Inform, then Inspire, Intimidate. `suiteID` 1–4 stays. Map: 1 influence, 2 intimidate, 3 inform, 4 inspire. Description tables: `v2influenceDescriptions`, `v2informDescriptions`, `v2inspireDescriptions`, `v2intimidateDescriptions`. Each pane is `width: 50%` `box-sizing: border-box` (left `border-right` inside that 50%). Header and suite-title tracks: 67% name / 15% Stat / **18%** Rank (`width`, border-box). Description rows: 82% / 18% Rank so Rank lines up with the header. Header `h2`s are a solid `#bdbdbd` bar (global `padding: 4px`, no T-045 island/clip). Suite-title `em` keeps the island. (Revised: T-012 left storage keys as empathize/lecture/tempt. T-045 `span *` island and `min-width: 15%` made Stat/Rank headers miss the value columns and punched the heading bar.)
- Current Emotions is a child table `v2currentEmotions` (`pageID`, `value`, `rank` 0–5). Payload `currentEmotions` is `{ id, value }[]`. The view draws six unlabeled cells in a 3×2 CSS grid, row-major (rank 0–2 then 3–5), heading **Current Emotions**. Short/missing arrays pad to six empty cells. Social Suite–style `#bdbdbd` 1px grid lines; `min-height: 17.38px`. Cells stay wrapped in `span` (stripe on the span). Leftover `p` / edit `input` use island `padding: 2px 1px` on the control (`edit-character.md`), not wrapper padding. The old `v2BasicCharacteristics.currentEmotions` varchar is copied into rank 0 then dropped. Boot script owns that DDL (`schema-on-boot.md`). (Revised: T-013 stored one string on basic characteristics. Shape is no longer the same as Descriptions.)
- Descriptions is the renamed v2 convictions store: table `v2descriptions` (was `v2convictions`). Payload `descriptions` only — no `convictions` key. Not goals or relationships. Each row is `{ id, key?, label, attackEmotion, defenseEmotion, rank }` (`rank` is `number | ''`). `label` varchar(500); emotions varchar(25) free text; `rank` is the drawn player number (not list order). One header row, Capacity-at-h2: **Descriptions** (`h2`, Label slot, global 13px grey bar) | **Attack** | **Defense** | **Rank** (`h2.minor-heading`, 10px oldClaude, centered like Na/N/Nb). Header and each data/insert/leftover `span` copy Capacity flex + matching `%` widths (first 38%, other three 20.6%). Keep h2 `padding: 4px`. Value `p`/`input` use island `padding: 2px 1px` border-box inside `min-height: 17.38px` (`background-clip: content-box`); data spans keep `gap: 1px` between value cells and do **not** add wrapper padding. One line of four value cells per row; cap 5 leftover pads. Missing array as `[]`. Overflow past `.page-type-one` 1068 is recorded, not compressed. (Revised: wrapper `padding: 2px 1px` plus inner `padding: 4px` grew leftover rows. Earlier: value cells filled the heading tracks with no gutter. Earlier: column labels were `em` with `flex: 1` / `6em` / `28px`. Earlier: one `value` string; `rank` stored but view ignored it.)
- `dieIndex` 0 draws no selection. Stored 1–6 map to d4–d20 (`selected` when `index === dieIndex - 1`). The Die row paints those six as PNGs (`d4.png` … `d20.png` in `app/src/assets/images/`), not the strings `d4`…`d20`. All six images show even when `dieIndex` is 0. Selected is Positions-style outline (`outline: 2px solid black; outline-offset: -1px`), not a black fill. Keep the grey die-cell boxes. `alt` is the die name only. v1 Integrity `d4!` text is out of scope.
- Defense `name` draws in the Defenses header, replacing the empty `<h2>` under **Defenses** (the Input slot). Header stays h1 + one 17.38px value row; no third line. Defense `notes` and each attack `notes` draw unlabeled below that block’s stats (after Cover / P. DR / DR; after Type / Rec). Bare value `<p>`, two-line min-height (`calc(2 * 17.38px)`), wrap and grow. All four attack slots get the block. Name and notes stay `varchar(150)`. (Revised: name was undrawn.)
- Favor prompt stays chrome. `divineRelationship` (`varchar(500)`) draws under it, notes-style wrap/grow. (Edit: `edit-character.md`.)
- Empty value cells keep one line of height (`min-height: 17.38px`, same as global `p` in `app/src/index.css`). Do not use a border to hold that height.
- Extra chrome to omit: Attack value underlines, Defense value underlines, Favor number boxes, Favor anointed outline box. Keep GeneralInfo `p.border`, Social Suite grid, Current Emotions 3×2 grid lines, Vitals boxes (including die-cell borders), Positions Neutral/W1 outlines, and the selected-die outline.

Rejected:
- Binding Descriptions to goals or relationships. Binding to the old `convictions` *payload key* while keeping both stores (T-014) — superseded by renaming the convictions *table* to descriptions. Descriptions as one `value` cell with silent index `rank`. A shared four-field array widget. Emotion `<select>` or Current Emotions as the pick-list. Two-line Description rows. Compressing other blocks so four cells still fit 1068px. Attack/Defense/Rank as `em`. CSS grid, subgrid, `<table>`, or `display: contents` for this header. Copying Capacity’s 10.3% band / 2.5% slash tracks. A full-width Descriptions bar above a second column-header row. Importing `Capacity.css` or a shared heading widget.
- Restyling all `p` (or global UI) to Kalam. npm `@fontsource/kalam` or self-hosted Kalam files. Kalam 300/700. Kalam on Positions, die cells, Anointed, or static slashes. Changing display `p.character-value` away from 15px / 17.38px. (Edit input boxes: `edit-character.md`.)
- Treating `dieIndex` 0 as d4.
- Labeled Specials/Notes heading on the notes block. A new notes column or field. `#bdbdbd` box or underline on notes. Hiding the block on empty-named attacks. Clip/ellipsis instead of wrap. Widening notes `varchar(150)`. Compressing other blocks so notes still fit 1036px. An extra Defenses header line for **Input**.
- A separate raw capacity cell. Editing Emotional Capacity bands other than Yb.
- A new migration framework for these patches (`schema-on-boot.md`).
- SVG die glyphs; CSS invert / second asset set for unselected; selected as black fill; capping die-row height to one text line; visually hidden text in addition to `alt`.
- Current Emotions as one string (T-013), a `text[]` column, or six named columns. Named labels on emotion cells. Heading shortened to Emotions.
