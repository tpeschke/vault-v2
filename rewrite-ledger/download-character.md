# Download a character
status: accepted   date: 2026-10-30

Decision: A v2 character downloads as one PDF from the view sidebar. The writer is `html2pdf.js` 0.14.0, one worker per `.page` card. `pdf-lib` 1.17.1 joins those PDFs into one file. There is no pregen control. The v2 card’s border box is US Letter in CSS pixels so the captured card and the PDF page are the same size.

Why: The designer named html2pdf.js and rejected v1’s per-page `html2canvas` plus `jsPDF.addImage` (2026-10-30). One html2pdf canvas of the whole stack sits near the browser canvas ceiling, so each card is its own worker. They confirmed `pdf-lib` as the join, left pregen out, and said to change the HTML page size to match the PDF page. jsPDF `letter` with unit `px` and hotfix `px_scaling` is 816×1056, which is 8.5×11 in at 96 px/in. Without that hotfix, jsPDF’s `px` unit is 96/72 and the numbers are not CSS pixels. Same day, later: the other sidebar buttons stay and are locked for the download, and Quick Edit view is turned off and left off. Same day, again: ruled lines, selected die faces, and Excalidraw frame names are painted in the clone. html2canvas 1.4.1 does not paint `repeating-linear-gradient` or `filter`, and its text baseline drops the frame name onto the stroke. Same day, again: the notes scene in the PDF grows away from the word Frame when `devicePixelRatio` is above 1. The worker’s clone shows the device-pixel bitmap as CSS pixels. The clone callback pins that image to the live canvas box.

Constraints it imposes:
- View mode only. On a real character the sidebar order is Edit (when `ownsThisCharacter`), then Download, then the quick-edit toggle. Download is not owner-gated and stays visible on `/v/blank` (`blank-sheet.md`). Hidden while editing. While a download runs the sidebar stays mounted: Edit, the quick-edit toggle, and Download render with HTML `disabled`, and their handlers do not run. On `/v/blank` the locked control is Download. The click sets `viewQuickEdit` false and capture waits for that paint, so `.page-shell` has no `view-quick-edit` and the toggle reads **Show Quick Edit Locations**. Finishing or throwing does not turn Quick Edit view back on. A second click does not start a second file. (Revised 2026-10-30: “hidden while a download is running” — **revised**. The buttons stay and are locked.)
- Capture every `.page` in `.version-two-shell`, DOM order, including type 4. The sidebar is not inside that set. Edit gutters are absent in view mode. html2pdf appends the clone on `document.body`, outside `.v2`. The worker adds class `v2` on `.html2pdf__container` before copying fields. Without that class the clone uses the unscoped `.page` box (828×1068) and the worker emits a second page.
- Each worker: `margin: 0`, `html2canvas.scale: 2`, jpeg quality 0.95, `enableLinks: false`, no page-break mode. `jsPDF`: unit `px`, format `letter`, orientation `portrait`, `hotfixes: ['px_scaling']`. After `toPdf`, that page is 816×1056. If it is not, stop.
- In the worker container, copy live `textarea` and text/number/search `input` values onto blocks in the clone. Leave checkbox, radio, button, file, and hidden inputs. Do not change the on-screen controls. (Revised 2026-10-30: the block’s forced `white-space: pre-wrap` — **revised**. The block copies the control’s computed font, padding, alignment, wrapping, and overflow. Ruled lines, selected dice, and frame names are the paint bullets below. “Copy live canvas bitmaps onto the clone canvases” — **revised**. html2pdf 0.14.0 replaces each `canvas` with an `img` whose `width` and `height` are the bitmap size. The notes-scene bullet is the binding rule.)
- Each replacement block copies computed `font-family`, `font-size`, `font-weight`, `font-style`, `line-height`, `letter-spacing`, `color`, padding, `text-align`, `white-space`, `overflow-wrap`, and overflow from the clone control. It does not assign `pre-wrap` itself. Width and height stay the live border box. `scrollTop` is copied from the live control. When the computed overflow is `visible`, the block uses `hidden`. `.v2 :where(textarea.character-value)` does not match the block, so the copied `font-size` and `line-height` are what keep 15px / 1.2.
- Ruled lines are a bitmap, not the stylesheet gradient. Targets: `.page3-contacts > .character-value`, `.page-type-two-notes > .character-value`, and `.page3-notes`. Bands are 17.38px `#fff` then 17.38px `#f3f3f3`, repeating every 34.76px, shifted by the live `scrollTop`. Set that image with `!important` so it beats `.v2 .page3-notes` and `.v2 .page-type-two-notes > p`. Set `background-attachment: scroll` as well. Those rules force `local`, and a second shift would move the bands off the text. View-mode page-2 notes are a `p`, so that `p` is painted in place. Relationship zebra stays the solid `#f3f3f3` on even `.page3-relationships-list > span`. Do not add row elements. Do not change sheet CSS.
- Selected die faces: bake each `.vitals-v2 .die-row p.selected img` with `ctx.filter` set to that image’s computed filter. The canonical filter is `page1-view.md`. The clone `img` `src` is that bitmap and its `filter` is `none`. Do not bake hover filters. Do not edit `Vitals.css` or the die PNGs.
- Frame names: each clone node whose id contains `-frame-name-` becomes an image of the live label’s text, pinned with `top`, `left`, `width`, and `height` from the live label inside `.excalidraw`, and `bottom: auto`. Rasterize at scale 2 with the live computed font and color. Measure the text before that scale. Clip to the content box. A name the live label already shows in full is drawn in full. A name the live label clips (`scrollWidth` greater than `clientWidth`) ends in `...`. Do not call `exportToCanvas`. Do not edit page type 4 or Excalidraw. The notes canvas stays the viewport drawing. The scene image uses that same `.excalidraw` rectangle.
- Notes scene: pair each live `.excalidraw` on the card with the clone’s `.excalidraw`, tree order. Counts must match. Walk that pair. A live `canvas` matches an `img` or a `canvas` in the clone. Pin it `position: absolute`, `margin: 0`, `z-index` from the live canvas, and `top`, `left`, `width`, and `height` from the live canvas rectangle minus the live `.excalidraw` rectangle. On an `img`, remove the `width` and `height` attributes and keep `src`. On a `canvas`, keep the bitmap attributes, copy the live bitmap 1:1 with `drawImage`, and set that same CSS box. Await `decode()` on an `img`. Do not walk a `canvas`’s children. Do not walk the whole card. Worker `html2canvas.scale` stays 2.
- The `toContainer` callback returns a promise that resolves after those images have decoded, before `toCanvas`.
- One download. Filename is `character.name` with `\ / : * ? " < > |` and control characters removed, trimmed, or `Blank` when that is empty, then `.pdf`.
- While it runs, show the v1-style banner: sticky, “Downloading”, the existing loading indicator. The sidebar stays mounted under that banner. (Revised 2026-10-30: “do not render the sidebar during that wait” — **revised**.)
- Client only. No backend route. No `features/` directory. Do not edit the v1 download path. Root `jspdf` stays `^3.0.3` for v1. `html2pdf.js` 0.14.0 depends on `jspdf` 4; that copy stays nested. `pdf-lib` is `1.17.1`.
- Page box: `v2-page-type.md`. This file does not resize v1.

Rejected:
- Pregen — designer, 2026-10-30.
- One `html2pdf().from(page-shell).save()` for the stack — one canvas of 15 cards at scale 2 is about 31,080 px tall, under Chrome’s rough ceiling and close enough that a phone canvas comes out blank.
- US Letter in mm with the 796×1036 card left as it is — the designer said to change the HTML page to match.
- Resizing the unscoped `.page` rule — that box is also v1. v1 stays 796×1036.
- Unmounting the sidebar for the download — **revised** the same day. The buttons stay and are locked. The banner stays.
- Copying `repeating-linear-gradient` onto the block — html2canvas 1.4.1 does not paint it.
- Rewriting the frame label from `bottom` to `top` and leaving it as DOM text — the glyphs still sit on the stroke.
- `exportToCanvas` for the notes card — default padding is 10. That crop moves the drawing on the letter page.
- A second die PNG, or editing the selected-die filter — `page1-view.md`.
- Forking html2canvas.
- Downsampling the notes bitmap to the CSS box before capture — html2canvas already scales that bitmap into the CSS box, and worker scale 2 would resample it again.
- Setting `html2canvas.scale` from `devicePixelRatio` — the letter page stays scale 2 and 816×1056. That option does not restore the CSS box the cloner drops.
- Forking html2pdf.js — the pin stays in `downloadCharacter.ts`.
